# 《植物大战僵尸2》中文版进化神器复刻

版本：**4.2.4**
作者：**p**

这是一个针对《植物大战僵尸2》中文版进化神器的复刻与分析工具，基于 Python 本地服务和浏览器界面实现。项目用于分析关卡规则、阳光成本、候选植物、随机索引和生成顺序，并提供可视化复刻界面。

## 功能

- 神器生成与神器序列复刻
- 世界关卡复刻、关卡导入和地图编辑
- 植物候选索引查询
- 0–500 阳光阶段查询（每 25 阳光一个阶段）
- 当前首索引、生成顺序和植物索引展示
- 候选黑名单预览
- 植物中文名、英文名、阳光成本和图片展示

## 运行

需要 Python 3.10 或更高版本。

```powershell
python artifact_web_server.py --host 127.0.0.1 --port 8787
```

然后打开：<http://127.0.0.1:8787>

## 主要文件

| 文件 | 说明 |
| --- | --- |
| `artifact_web_server.py` | 本地 HTTP 服务和 JSON 接口 |
| `artifact_reproduce_modular.py` | 植物候选池、随机洗牌和关卡复刻逻辑 |
| `web/index.html` | 浏览器工作台界面 |
| `规则/` | 关卡、植物、图片和规则资源 |
